# xDNS 使用文档

自托管的轻量 DNS 管理平台,统一管理 **Cloudflare**、**DNSPod(腾讯云独立版)** 与**阿里云 ESA(边缘安全加速)** 的域名解析记录。

- **技术栈**:Node.js 22+ (Express + 内置 SQLite) + Vue 3 + Vite,PWA / 暗色模式 / 移动端适配
- **部署**:Docker 一键运行,SQLite 单文件持久化

## 访问与登录

1. 打开部署地址:本机生产环境为 `18089` 端口(默认容器端口 `3090`,以实际部署为准);
2. 首次启动自动创建管理员 `admin`:若部署时设置了 `XDNS_ADMIN_PASSWORD` 则用它登录,否则初始密码打印在容器日志(`docker logs xdns`)中;
3. 登录后请立即在账户设置中修改密码。

## 添加服务商账户

进入「账户」页面,选择服务商类型并填入 API 密钥(Token 以 AES-256-GCM 加密存储)。

### Cloudflare

1. Cloudflare 控制台 → My Profile → API Tokens → Create Token;
2. 推荐模板「Edit zone DNS」,Zone Resources 限定需要的域名(最小权限);
3. 也支持 Global API Key + 邮箱(不推荐)。

### DNSPod(独立版 dnsapi.cn)

1. 控制台 → 密钥管理 → 创建 API Token;
2. Token 格式为 `数字ID,Token`(英文逗号分隔,两者缺一不可);
3. 常见错误:只复制了后半段、误用腾讯云 SecretId/SecretKey、账号绑定了 IP 白名单。

### 阿里云 ESA

1. 阿里云控制台 → RAM 访问控制 → 创建用户(勾选 OpenAPI 调用访问)→ 创建 AccessKey;
2. 为该用户授予 ESA 权限(推荐最小化,如 `AliyunESAFullAccess`);
3. 在 xDNS 中填写 `AccessKey ID` 与 `AccessKey Secret`;
4. 国际站账号需由部署方设置 `XDNS_ESA_ENDPOINT=esa.ap-southeast-1.aliyuncs.com`。

## 记录管理

- 支持 A / AAAA / CNAME / MX / TXT / NS / CAA 等 7+ 种记录类型的增删改查;
- **Cloudflare**:CDN 云朵代理一键开关、TTL 自动/手动、锁定记录保护;
- **DNSPod**:分线路解析(电信/联通/移动…)、记录启停;
- **阿里云 ESA**:站点接入管理、「加速」开关(对应记录 Proxied 字段)、TTL 自动/手动;根域名记录的主机名即站点名;
- **备注(remark)**:可编辑、可搜索、随导入导出;
- 服务端写入校验:IP 格式、域名格式、CAA 格式、TTL/MX 优先级范围,错误在到达服务商前拦截。

## 批量操作与导入导出

- **批量操作**:勾选记录后可批量删除、启停、切换 CDN/加速开关、批量编辑(记录值精确替换/统一设置、主机名查找替换、TTL、DNSPod 线路,任意组合);执行前有变更预览,执行时显示逐条进度;
- **导入导出**:JSON / CSV 格式,带预览与重复检测;CSV/JSON 可往返无损。

## 解析生效检测

- 对单条记录或整个域名执行公网解析生效检测(1.1.1.1 / 8.8.8.8 等递归服务器比对);
- 检测接口限流:每用户每分钟 240 次。

## 安全与审计

- **会话**:服务端存储,HttpOnly Cookie,7 天有效;修改密码后所有会话失效;
- **登录保护**:每 IP 15 分钟内失败 10 次锁定;
- **Token 静态加密**:服务商密钥加密落库;主密钥推荐由部署方通过 `XDNS_SECRET` 指定,未设置时自动生成在 `data/.secret.key`;
  - ⚠️ **更换主密钥后旧密文无法解密**,所有账户 Token 需重新录入,换密钥前请先记下各账户密钥;
- **审计日志**:登录(含失败)、改密、账户增删、记录变更、CDN/启停切换均记录用户/IP/时间。

## 反向代理(HTTPS)

- 推荐 Caddy 自动证书反代到 `127.0.0.1:3090`;Nginx 配置示例见 [README](../README.md);
- 反代与 xDNS 不在同一台机器/容器时,需设置 `XDNS_TRUST_PROXY=1`,否则登录限流与审计日志会记录成反代 IP;
- HTTPS 下会话 Cookie 自动附加 `Secure` 标记。

## 数据与迁移

- 全部数据(SQLite 数据库 + 密钥文件)落在挂载的 `./data` 目录,**备份该目录即可完成迁移**;
- 每日操作建议:定期备份 `data/` 目录;删除记录前善用批量操作的变更预览。

## 常见问题

| 现象 | 处理 |
|------|------|
| DNSPod 账户验证失败 | 检查 Token 是否为 `ID,Token` 完整格式;勿用腾讯云 SecretId;确认无 IP 白名单 |
| 换了部署环境后账户报错 | 主密钥(`XDNS_SECRET` / `data/.secret.key`)变了,旧密文无法解密,需重新录入各账户 Token |
| 限流把真实 IP 记成同一 IP | 跨机反代场景设置 `XDNS_TRUST_PROXY=1` |
| admin 密码丢失 | 由部署方通过 `XDNS_ADMIN_PASSWORD`(仅首次生效)重建,或直接查看容器日志中的随机初始密码(未改密前) |
